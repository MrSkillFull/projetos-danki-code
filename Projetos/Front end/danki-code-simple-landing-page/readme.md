# Danki Code Simple Landing Page

## Objetivo

Aplicar conhecimentos teóricos adquiridos no módulo básico do curso `Frontend Completo` da **Danki Code** em um projeto prático real.

## Escopo

Trata-se de uma landing page (página dedicada a conversão, onde o usuário entra para realizar uma ação específica. Ex: preencher um formulário, baixar material ou comprar um produto) fictícia, criada apenas com ![Static Badge](https://img.shields.io/badge/HTML-black?logo=HTML5) e ![Static Badge](https://img.shields.io/badge/CSS3-black?logo=CSS). O layout foi desenhado pelo instrutor e CEO da Danki, `Guilherme Grillo`.

## Conclusão

O objetivo do projeto foi alcançado com facilidade.

## Visualização do projeto

Para visualizar meu trabalho siga esses passos:

1. clone ou faça download do repositório
2. abra o `index.html` no seu navegador favorito.
