# Danki Code — Desenvolvimento Web Completo

## Projeto — Cena Landing Page

O projeto é uma landing page de um cliente real da Danki Code, este design foi reaproveitado no curso. Nele foram usados apenas ![HTML Badge](https://img.shields.io/badge/HTML-black?logo=HTML5) e ![CSS Badge](https://img.shields.io/badge/CSS3-black?logo=CSS).

 ## Objetivo

 O objetivo era colocar em prática os conhecimentos adquiridos no módulo de abertura do curso "Desenvolvimento Web Completo" do Danki Code em um projeto real.

 ## Conclusão

 Objetivo atingido com facilidade, uma simples lading page com formulário, cta e um mini backdrop. Nesse projeto eu pude aplicar de forma prática o seletor `nth-child()` para intercalar entre os itens do backdrop.

 ## Visualização do projeto

 Para visualizar esse projeto siga essas etapas:

 1. Clone ou baixe o `.zip` deste repositório
 2. Abra o `html.index` no seu navegador favorito
