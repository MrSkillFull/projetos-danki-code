# Danki Code — Desenvolvimento Web Completo
## Projeto — Starbucks Simple Landing Page

O projeto é apenas uma landing page simples clonada de uma versão legado do starbucks. Nele foram usados apenas ![Static Badge](https://img.shields.io/badge/HTML-black?logo=HTML5) e ![Static Badge](https://img.shields.io/badge/CSS3-black?logo=CSS).

 ## Objetivo

 O objetivo era colocar em prática os conhecimentos adquiridos no módulo de abertura do curso do Guilherme Grillo em um projeto real.

 ## Conclusão

 O objetivo do projeto foi atingido, o design ficou incrivelmente parecido com o proposto na atividade.

 ## Problemas conhecidos

 - Semântica: o projeto não está 100% semântico, eu usei divs em lugares onde cabia o uso de `main`, `section`, `article` e `ul>li`.
 - Responsividade: o projeto não está responsivo para visualização mobile. Mas, essa não é uma preocupação, já que não era essa a proposta da atividade no momento.
