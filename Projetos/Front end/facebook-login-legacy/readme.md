# Danki Code — Desenvolvimento Web Completo

## Projeto — Facebook Login Legacy

O projeto é a página de login clonada de uma versão legado do Facebook. Nele foram usados apenas ![Static Badge](https://img.shields.io/badge/HTML-black?logo=HTML5) e ![Static Badge](https://img.shields.io/badge/CSS3-black?logo=CSS).

 ## Objetivo

 O objetivo era colocar em prática os conhecimentos adquiridos no módulo de abertura do curso "Desenvolvimento Web Completo" do Danki Code em um projeto real.

 ## Visualização do projeto

 Para visualizar o projeto siga esses passos:

 1. Clone este repositório
 2. Abra o `index.html` em seu navegador favorito

## Conclusões

O objetivo do projeto foi alcançado. Tive a oportunidade de aperfeiçoar meus conhecimentos com grid design e responsividade.

## Problemas conhecidos

1. Footer da página original ausente: eu deliberadamente não inclui o footer da página original no escopo deste projeto por ser extremamente simples e já fazer parte do conteúdo dominado por mim.
2. Cores incorretas: eu não quis usar as cores oficiais do Facebook por questões éticas e de simplicidade.
3. Logo oficial ausente: pelo mesmo motivo citado acima, a logo oficial do Facebook não foi usada para esse projeto.
