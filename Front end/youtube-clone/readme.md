## Objetivo

O objetivo deste projeto, assim como o anterior, é aplicar os conhecimentos aprendidos no módulo básico do curso `Frontend Completo` da **Danki Code** em um projeto real e de complexidade baixa/média.

## Escopo

Desta vez, eu irei clonar a homepage do Youtube (legado), preservando algumas de suas funcionalidades principais e seu design original utilizando apenas ![Static Badge](https://img.shields.io/badge/HTML-black?logo=HTML5) e ![Static Badge](https://img.shields.io/badge/CSS3-black?logo=CSS).
